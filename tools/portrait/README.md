# 임시 초상화 누끼 도구

유출 단계에서 **공식 아이콘이 아직 없을 때**, 흰 배경(단색 배경) 일러스트로 256×256 투명 초상화를 만드는 도구.
웹앱(`web/`)·npm 빌드와 무관한 독립 Python 도구다.

## 먼저 확인: 공식 아이콘이 있는가?

nanoka `character.json`의 `icon` 값(`.../IconRoleHead256/T_IconRoleHead256_<번호>_UI...`)이 있으면 그걸 받아 쓴다. 이 도구는 필요 없다.

```
https://static.nanoka.cc/assets/ww/UIResources/Common/Image/IconRoleHead256/T_IconRoleHead256_<번호>_UI.webp
```

## 준비

```bash
python3 -m venv tools/portrait/.venv
tools/portrait/.venv/bin/pip install -r tools/portrait/requirements.txt
```

## 사용법

1. 원본을 **정사각형**으로 크롭한다 (얼굴이 가운데, 기존 초상화와 비슷한 구도). 크기는 자유, 256으로 줄여서 처리한다.
2. 실행 + 확인용 이미지 생성:
   ```bash
   tools/portrait/.venv/bin/python tools/portrait/cutout.py 원본.png web/public/characters/<id>.png --preview /tmp/<id>-preview.png
   ```
3. 확인용 이미지(왼쪽 어두운 배경, 오른쪽 자홍 배경, 32px 좌표 격자)를 본다.
   - **지워졌는데 남아야 하는 곳**(흰 꽃잎·흰 옷이 뜯겨 나감) → `--keep 'x,y,r'`
   - **남았는데 지워야 하는 곳**(머리카락 사이 흰 배경) → `--clear 'x,y,r'`
   - 좌표는 256 기준. 여러 곳은 `;`로 구분: `--keep '217,203,6;238,190,7'`
   - 힌트는 점에서 반경 `r` 안의, 점과 이어진 배경색 영역만 바꾼다. 꽃잎 하나에 점 하나, 반경 5~7 정도
4. 힌트를 넣고 다시 실행 → 확인용 이미지로 재확인. 이후 앱에서 도감 카드·파티 슬롯·이미지 저장 결과 확인

### 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--seed-edges` | `top,left,right` | 배경이 닿아 있는 테두리. 몸이 닿는 쪽(보통 `bottom`)은 빼야 옷이 안 지워짐 |
| `--bg-tol` | 18 | 배경색과의 차이가 이 이하면 배경 후보 |
| `--close` | 2 | 머리카락 사이 틈 메우기 반경(px) |
| `--band` | 3 | 색으로 투명도를 계산하는 경계 두께(px) |
| `--keep` / `--clear` | - | 수동 힌트 `'x,y,r;...'` |
| `--preview` | - | 확인용 이미지 경로 |

## 원리 (릴리 사례)

릴리 임시 누끼(#28 → #32)를 공식 아이콘(#38)과 비교해서 차이를 줄이는 방향으로 만들었다.

| | 실루엣 일치율 | 구멍(px) | 흰 테두리(px) | 어두운 배경 색 오차 |
|---|---|---|---|---|
| 기존 임시 누끼 | 0.973 | 764 | 776 | 9.12 |
| `cutout.py` 자동 | 0.987 | 265 | 265 | 7.08 |
| `cutout.py` + 힌트 | 0.992 | 46 | 273 | 6.29 |

1. **모양으로 자르기**: 지정 테두리와 이어진 배경만 지운다. 안쪽 흰색(옷·하이라이트)은 남긴다
2. **머리카락 틈 메우기**: 256px에서 1~4px 틈은 파지 않고 덩어리로 둔다 (공식 아이콘도 그렇다)
3. **갇힌 배경 주머니 제거**: 머리카락 사이에 완전히 갇힌 순백 영역이 바깥 배경 가까이 있으면 배경
4. **선화 기준 경계**: 공식 아이콘 외곽은 어두운 선이다. 근처 가장 어두운 색으로 투명도를 계산하고 반투명 픽셀에서 흰색을 빼서 흰 테두리를 없앤다
5. **한계**: 흰 배경에 닿은 흰 물체(백합 꽃잎)는 테두리 선이 끊기면 색으로 구분할 수 없다 → 힌트로 해결. 원본 그림 자체가 윤곽선만 있는 부분은 복원 불가

## 기본값 조정 (선택)

새 캐릭터의 공식 아이콘이 나오면, 임시 누끼와 비교해 기본값을 다듬을 수 있다.

```bash
tools/portrait/.venv/bin/python tools/portrait/score.py 공식.webp 임시1.png 임시2.png
```
