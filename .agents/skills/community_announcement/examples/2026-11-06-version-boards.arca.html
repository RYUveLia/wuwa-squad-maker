안녕하세요.


매트릭스 파티 사이트 만들고 업데이트 했던 깡계 띵붕이입니다


이번엔 명조 업데이트는 아니지만, 버전별로 파티를 따로 짤 수 있게 매트릭스 파티 메이커를 크게 업데이트 했습니다.


3.5부터 3.8(유출)까지 버전을 골라서 그 버전 기준으로 파티를 짤 수 있습니다.



https://wuwa-squad-maker.vercel.app/


PC, 모바일 가능합니다


[이미지: 1-main.png → 표시 너비 902px (가로 꽉)]


[이미지: 6-mobile.png → 표시 너비 390px]



이용 방법


- 접속 시 봇 검사 하는데 광고차단 쓰면 건너뛰기


- 위에서 버전(3.5 / 3.6 / 3.7 / 3.8)을 고릅니다


- 왼쪽에서 누르거나 드래그 하면 파티에 넣고, 파티에서 누르면 빠집니다


이거로 매트릭스 파티 편성 계획 짜시면 됩니다



기능


- 파티 끼리 스왑 가능합니다


- 가지고 있는 공명자만 확인 가능합니다.


- 이미지로 저장 지원합니다.


- 내보내기 / 불러오기로 다른 사람들과 공유 가능합니다.


- 버전별로 파티를 따로 저장합니다. 유출 정보는 3.8 탭에서 볼 수 있습니다.



추가 및 변경 사항


- 버전 선택 추가 (3.5 / 3.6 / 3.7 / 3.8 유출)


- 버전마다 파티가 따로 저장됩니다. 3.6 파티와 3.7 파티가 섞이지 않습니다.


- 선택한 버전에 맞춰 도감(그 버전까지 출시된 공명자), 2회 시즌 버프(3.5 치사 / 3.6 데니아 / 3.7 린네 / 3.8 루실라), 회로 버프가 바뀝니다.


- 3.5 회로 버프를 추가했습니다.


- 유출 포함 버튼은 없앴습니다. 3.8 탭에서 유출 정보로 파티를 짤 수 있습니다.


[이미지: 2-migration.png → 표시 너비 640px]


- 예전에 저장해둔 파티가 있으면 처음 접속할 때 어느 버전으로 옮길지 물어봅니다.


- 회로와 공명자를 보고 버전을 추천해 줍니다. (예: 데니아 2회 + 3.6 회로 → 3.6 추천)


- 추천 버전으로 옮기면 회로가 유지되고, 다른 버전으로 옮기면 회로는 초기화됩니다.


[이미지: 3-import-choice.png → 표시 너비 450px]


- 내보내기 코드에 버전이 함께 저장됩니다.


- 다른 버전 코드를 불러오면 "그 버전에 넣기 / 지금 보는 버전에 넣기" 중에 고를 수 있습니다. 예전 코드도 그대로 불러올 수 있습니다.


[이미지: 5-import-modal.png → 표시 너비 450px]


- 불러오기 창에서 다른 버전의 파티를 가져올 수 있습니다. (회로는 초기화, 그 버전에 없는 공명자는 제외)


[이미지: 4-image-export.png → 표시 너비 640px]


- 이미지로 저장할 때 버전(v3.6 등)이 함께 표시됩니다.


- 저장된 데이터가 꼬여도 사이트가 멈추지 않도록 수정했습니다.
